Make your videos Pi-ready

Drop videos here. They're checked against what the Pi's hardware decoder can play, and anything that would stutter is re-encoded to HEVC (H.265), up to 4K at 60 fps. Everything runs in your browser using your machine's hardware encoder. Nothing is uploaded.

This browser can't convert video. It lacks the WebCodecs API, which this page uses for decoding and encoding. Use a current Chrome, Edge or Safari. You can still drop files to check them.

Checking…

What this does

  • Checks the codec and resolution of each file. HEVC at any size, and H.264 up to 1080p, decode in hardware on a Pi 4 / Pi 5 and are marked OK. Everything else (4K H.264, VP9, AV1, ProRes…) is flagged.
  • Re-encodes flagged files to HEVC in an MP4 with a 2-second keyframe interval, which keeps looping and seeking snappy in mpv. Resolution is capped at 4K and frame rate at 60 fps. Nothing is ever upscaled: a 1080p 30 fps source stays 1080p 30 fps. Blowing it up to 4K 60 would only make the file bigger, and the kiosk outputs 1080p anyway.
  • Audio is kept as is when the container allows it (AAC, MP3, Opus), otherwise it's converted.
  • Files that are already OK can still be converted if you want to shrink them or normalise everything to one format.

Browser support

Encoding uses the browser's hardware encoder through the WebCodecs API. HEVC encoding is available in Chrome and Edge on macOS and Windows with a recent GPU, and in Safari on Apple silicon. Firefox and most Linux browsers can't encode HEVC; the page then falls back to H.264 at 1080p, which also plays fine on the Pi. On Chrome and Edge the output streams straight to a file you pick; elsewhere it's held in memory until the download, so keep very large files for a Chromium browser.

Tips

  • FAT32 sticks can't hold files over 4GB. Use exFAT for long 4K videos.
  • A 4K 60 fps HEVC file runs at roughly 30 Mbps, so about 13GB per hour. The 1080p HEVC preset is a quarter of that and looks identical on the kiosk's 1080p output.
  • Expect conversion to run at a few times real time on a laptop with a hardware encoder.
  • Prefer the terminal? The repository's scripts/check-video.sh does the same check and prints an ffmpeg command.
